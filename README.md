# A House Divided — Promise & Practice (Unit 2, Part Two)

An interactive, offline-friendly U.S. History hub on the road to the Civil War,
the war itself, and Reconstruction (1854–1877).
Built by ShadowDog Digital Studios for Waukegan High School.

## What's in this folder
- `index.html` — the hub (the start page students open)
- `ch6/` … `ch10/` — the five chapter decks
- `ch6/<topic>/` — the seven Chapter 6 deep-dive lessons
- `.nojekyll` — tells GitHub Pages to serve the folders as-is **(do not delete)**

## Deploy to GitHub Pages
1. Upload **everything inside this folder** to the **root** of the repo
   (`index.html` must sit at the top level, not inside a subfolder).
2. Repo -> **Settings -> Pages -> Deploy from a branch -> `main` -> `/ (root)`** -> Save.
3. Live at: `https://shadowdogstudios-web.github.io/<repo-name>/`

Keep the hub and all chapter/deep-dive folders together in the same repo —
the hub links to them with relative paths.
